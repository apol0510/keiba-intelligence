## 2. 変更（本 PR）

- `/login`: 404 は「このメールアドレスは登録されていません。…はじめての方は無料会員登録から始められます。」＋「無料会員登録へ進む」。画面下の案内も `/register` へ。
  403 は「このアカウントではログインできません。お問い合わせページからご連絡ください。」（意味は不変）。
  送信成功時に「開いたブラウザでだけ有効・長押しでブラウザで開く・有効期限 15 分」の補足。
- 帯: **ゲストだけ**、主要 CTA の下に控えめな文字リンク「登録済みの方はログイン」。ログイン済み・プレビューでは出さない。主要 CTA の数は 1 のまま。
- GA4 `ki_login_link_result{result: sent|not_found|blocked|error}`（FUNNEL_2026_10.md と同じ契約・PII なし）。

## 4. 実験として扱う

| 項目 | 内容 |
|---|---|
| 問題 | 既存会員がログインへ、未登録者が無料登録へ、迷わずに進めない（§1） |
| baseline | `/login` の送信結果・帯のログインリンクのクリックは **未計測**（2026-10-19 以前はイベントなし）。2026-09 の決済 8 件中、ログインが 7 日ごとの人・短時間に連続発行した人がいた（RETENTION §1） |
| 仮説 | 未登録者の一部が無料登録を完了し（`ki_signup_result{sent}` が増える）、セッション切れの会員が帯からログインする。送信後の補足で同一人物の連続発行が減る |
| 介入 | §2。価格・権利・実績表示・主要 CTA の数は不変 |
| 期待結果 | `ki_login_link_result{not_found}` の後の `/register` 到達と `ki_signup_result{sent}`、帯からの `/login` 遷移（page_referrer が無料予想ページ）、同一日の `ki_login_link_result{sent}` 連続件数の減少 |
| 評価期間 | 2026-10-20 〜 2026-11-16（FUNNEL_2026_10.md と同じ 28 日） |
| 判断 | 有害（苦情・誤案内）が無ければ維持。帯のリンクが主要 CTA のクリックを奪う兆候（`/register` 到達の減少）があれば戻す |

🔴 母数が小さいため統計的な判断はできない。件数を記録して定性的に判断する。
